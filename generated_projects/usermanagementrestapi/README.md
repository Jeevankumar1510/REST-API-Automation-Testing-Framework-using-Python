# User Management REST API - API Automation Testing Suite

Automated REST API testing suite generated by the **Intelligent API Automation & CI/CD Platform**.

- **Target Base URL:** `http://127.0.0.1:8000`
- **Framework:** Python, Pytest, Requests
- **Test Scenarios:** 46 automated test cases

## How to Execute Tests

```bash
# 1. Install dependencies
pip install -r requirements.txt

# 2. Run all tests with HTML report
pytest

# 3. Run selective test markers
pytest -m functional
pytest -m negative
pytest -m auth
pytest -m performance
```
